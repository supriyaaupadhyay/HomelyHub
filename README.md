# 🏡 HomelyHub

HomelyHub is a full-stack MERN rental application featuring **Trip Genie**, an AI travel assistant that generates custom day-by-day itineraries and matches them with available property listings.

---

## 🚀 Tech Stack
- **Frontend:** React, Vite, React Router, Axios, Tailwind/CSS
- **Backend:** Node.js, Express.js, MongoDB, Mongoose, Groq SDK
